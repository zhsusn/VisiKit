# Photo Organizer - 照片整理工具

一个纯本地的照片智能整理工具，帮你解决历史照片混乱、重复备份的问题。

## ✨ 功能特点

- 🔍 **智能扫描** - 递归扫描多目录，支持常见图片格式
- 🗑️ **精准去重** - 文件哈希精确匹配 + 感知哈希相似检测
- 📂 **自动分类** - 基于规则的智能分类（人物/景物/文档/宠物/截图等）
- 📅 **时间归档** - 按拍摄时间自动整理到文件夹
- 🖥️ **图形界面** - **Flet现代化界面**，美观流畅
- 💻 **命令行** - 支持CLI批量处理
- 🔒 **完全本地** - 零上传，保护隐私
- 📝 **重复报告** - 生成详细的重复文件对比报告
- 🛡️ **安全操作** - **只移动不删除**，重复文件单独存放

## 📦 安装

### 环境要求
- Python 3.10+
- 可选：GPU加速（CUDA）用于大规模处理

### 安装步骤

```bash
# 克隆/下载项目
cd photo-organizer

# 创建虚拟环境（推荐）
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# 或 .venv\Scripts\activate  # Windows

# 安装依赖
pip install -e .

# 如需GUI
pip install ttkbootstrap
```

## 🚀 使用方法

### 图形界面

```bash
python run.py
```

**界面特点：**
- 🎯 **四步流程**：源配置 → 策略配置 → 执行预览 → 执行监控
- 👁️ **预览确认**：虚拟目录树 + 重复文件对比（安全核心）
- 🎴 **卡片式配置**：去重/时间/分类三大策略卡片
- 📊 **仪表盘监控**：实时进度 + 统计信息 + 日志
- 🛡️ **安全机制**：模拟模式、操作确认、重复对比

### 命令行

```bash
# 1. 扫描照片
photo-organizer scan /path/to/photos --output scan.txt

# 2. 分析重复（预览）
photo-organizer dedup /path/to/photos --similar

# 3. 分类照片
photo-organizer classify /path/to/photos

# 4. 完整整理流程（GUI会自动处理重复文件）
photo-organizer organize /path/to/photos /path/to/output \
    --classify --date-format month --mode copy
```

## 📁 整理规则

### 安全原则

⚠️ **本程序只移动文件，绝不删除任何原始文件**

- 重复文件会被移动到 `_重复文件` 目录
- 可随时从 `_重复文件` 目录恢复
- 自动生成详细的操作报告

### 去重逻辑

1. **精确重复** - MD5哈希完全一致，100%准确
2. **相似照片** - 感知哈希(pHash)，检测缩略图、轻微编辑的重复

### 分类规则

| 类别 | 识别依据 |
|-----|---------|
| 人物 | 文件名关键词、竖屏比例、人像EXIF |
| 景物 | 默认类别、风景关键词 |
| 文档 | A4比例、扫描关键词、无相机EXIF |
| 宠物 | 宠物关键词 |
| 美食 | 食物关键词 |
| 截图 | 屏幕比例、截图文件名、无EXIF |

### 输出目录结构

```
输出目录/
├── 人物/
│   └── 2024-03/
│       ├── 20240315_143052_自拍.jpg
│       └── 20240320_093000_合影.jpg
├── 景物/
│   └── 2024-03/
│       └── 20240321_120000_风景.jpg
├── 文档/
│   └── 2024-03/
│       └── 20240322_150000_发票.jpg
├── _重复文件/              # 重复文件存放处
│   ├── 20240321_173659_photo2.jpg
│   └── 20240321_173700_IMG_0001.jpg
├── _照片整理报告.md         # 详细报告
└── _照片整理报告.json       # 数据报告
```

## ⚙️ 配置选项

### 日期格式
- `year` - 2024/
- `month` - 2024-03/ (默认)
- `day` - 2024-03-21/

### 操作模式
- `copy` - 复制，保留原文件（安全）
- `move` - 移动，删除原文件（节省空间）
- `simulate` - 模拟，不执行操作（预览）
