# Photo Organizer 使用指南

## 快速开始

### 1. 安装依赖

```bash
pip install pillow imagehash exifread

# 可选：安装 ttkbootstrap 获得更美观的界面
pip install ttkbootstrap
```

### 2. 启动程序

```bash
python run.py
```

或

```bash
python run_tkinter.py
```

## 使用流程

### 第一步：选择目录

1. 点击 **"添加目录"** 选择包含照片的文件夹
2. 可以添加多个源目录（如多个备份位置）
3. 选择 **输出目录**（整理后的照片存放位置）

### 第二步：配置选项

| 选项 | 说明 | 推荐设置 |
|-----|------|---------|
| **智能去重** | 检测重复文件 | ✅ 开启 |
| 去重模式 | 精确/相似 | 精确重复（速度快） |
| **自动分类** | 按内容分类 | ✅ 开启 |
| 日期格式 | 归档方式 | 按年月（2024-03/） |
| 重复文件处理 | 移动/保留 | 移动到重复目录 |

### 第三步：执行整理

点击 **"🚀 开始整理"** 按钮，程序将自动执行：

1. 🔍 **扫描** - 递归扫描所有照片
2. 🗑️ **去重** - 找出重复文件
3. 📂 **分类** - 识别人物/景物/文档等
4. 📁 **归档** - 按时间整理到文件夹
5. 📦 **移动重复** - 重复文件单独存放
6. 📝 **生成报告** - 详细的操作记录

## 重复文件报告

整理完成后，会自动生成两种格式的报告：

### Markdown 报告 (`_照片整理报告.md`)

适合人工阅读，包含：
- 统计摘要（总数、重复数、节省空间）
- 每个重复组的详细信息
  - 保留的文件（最优版本）
  - 移走的重复文件
- 操作失败记录

### JSON 报告 (`_照片整理报告.json`)

适合程序处理，包含完整的数据结构。

## 安全说明

⚠️ **重要提示**

1. **本程序只移动文件，不删除任何文件**
2. 重复文件被移动到 `_重复文件` 目录，可随时恢复
3. 建议首次使用时选择 **"仅模拟"** 模式测试
4. 整理前建议备份重要数据

## 分类规则

| 类别 | 识别依据 |
|-----|---------|
| 人物 | 文件名关键词、竖屏比例 |
| 景物 | 默认类别、横屏风景照 |
| 文档 | A4比例、扫描关键词 |
| 截图 | 屏幕比例、截图文件名 |
| 宠物 | 宠物关键词 |
| 美食 | 食物关键词 |

## 故障排除

### 程序无法启动

**检查依赖:**
```bash
# 安装核心依赖
pip install pillow imagehash exifread

# 可选：安装 ttkbootstrap 获得更好外观
pip install ttkbootstrap

# 检查 Python 版本（需要 3.10+）
python --version
```

### 扫描不到照片

- 确认选择了正确的目录
- 确认照片格式受支持（JPG、PNG、GIF、BMP、TIFF、WebP、HEIC）
- 检查是否有权限访问该目录

### 重复文件检测不准确

- 尝试切换去重模式（精确/相似）
- 相似模式可能产生误判，建议以精确模式为主

## 高级用法

### 命令行模式

```bash
# 扫描
python -m photo_organizer scan /path/to/photos

# 去重分析
python -m photo_organizer dedup /path/to/photos --similar

# 完整整理
python -m photo_organizer organize /source /output --classify
```

### 自定义分类规则

编辑 `src/photo_organizer/classifier.py` 中的 `keyword_rules` 字典。
