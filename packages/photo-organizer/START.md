## 新界面使用流程 (v2.0)

### 📋 四步流程说明

Photo Organizer v2.0 采用**"配置-预览-执行"**流程，确保安全可靠：

```
Step 1: 源配置 → Step 2: 策略配置 → Step 3: 执行预览(可选) → Step 4: 开始整理
```

### Step 1: 源配置 📁

1. 点击 **"➕ 添加目录"** 选择照片来源文件夹（支持多选）
2. 点击 **"浏览..."** 选择输出目录
3. 查看磁盘空间估算（实时更新）
4. 点击 **"下一步"**

### Step 2: 策略配置 ⚙️

配置三项策略卡片：

| 卡片 | 说明 |
|------|------|
| **🔍 智能去重** | 选择精确重复(MD5)或相似照片(pHash) |
| **📅 时间归档** | 按年/年月/年月日组织文件夹 |
| **📂 内容分类** | 自动分类为人物/景物/其他 |

**操作模式**：
- 复制（保留原文件，最安全）
- 移动（节省空间）
- 仅模拟（预览不执行）

**预览选项（关键改进）**：
- ✅ **执行前预览（推荐）**：先分析预览，再确认执行
- ⬜ **跳过预览**：对熟悉用户，直接开始整理

根据预览选项，按钮会变化：
- 启用预览：显示 **"分析并预览 →"**
- 跳过预览：显示 **"开始整理 →"**

### Step 3: 执行预览 👁️（可选）

如果启用了"执行前预览"，进入此步骤：

**左侧**：虚拟目录树预览，显示整理后的完整结构
  - 🟢 绿色 = 新增文件
  - 🔵 蓝色 = 移动文件
  - 🟡 黄色 = 重复文件
  
**右侧**：重复文件对比视图
  - 查看重复组列表
  - 选择保留或删除

确认无误后，点击 **"确认执行"**

如果跳过了预览，直接进入步骤4开始整理。

### Step 4: 开始整理 🚀

实时监控整理进度：
- 总体进度条 + 百分比
- 当前处理文件名
- 已处理/总数统计
- 剩余时间估算
- 实时日志输出

完成后点击 **"完成"**

## 界面特性

### 现代化设计
- 四步流程指示器（Stepper）
- 卡片式策略配置
- 左右分栏预览对比（可选）
- 仪表盘式执行监控

### 安全机制
1. **预览确认**（可选）：执行前必看虚拟目录树
2. **重复对比**：左右分栏对比重复文件
3. **操作确认**：移动模式二次确认
4. **模拟模式**：可先模拟不执行
5. **预览可跳过**：对熟悉用户提高效率

### 智能分析
- 自动扫描多目录
- MD5精确去重 + pHash相似检测
- 智能分类（人物/景物/其他）
- 磁盘空间预估（实时更新）
